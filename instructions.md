# 🚀 Counterism Studio V4 Instructions

## 🛠️ Installation
1. Ensure `node` and `npm` are installed.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Install `ffmpeg` on your system.

## 🎬 Rendering
To render all scenes defined in the JSON:
```bash
npm run render
```

Individual scene output will be located in:
`renders/overlays/remotion/updated_scene_SC_XX.mp4`

## 🧪 Preview
To open the Remotion Preview:
```bash
npm start
```
