# PRODUCTION DESIGN PROTOCOL: STUDIO V4

## 🎯 DESIGN INTENT
Produce high-end documentary motion graphics (Vox/Polymatter aesthetic). Every scene must feel like a precision-engineered broadcast segment.

## 🛠️ TECHNICAL ARCHITECTURE
1. **COORDINATES**: 1920x1080. Anchors are center-based.
2. **PARALLAX DEPTH**: Shapes (10), Graphs (25), Charts (40), UI (45), Text (60). Use this to create 3D depth.
3. **TYPOGRAPHY**:
   - HEADER: Concise (2-3 words).
   - STYLE: Bold, high-contrast.
   - SPLIT: ALWAYS use `splitMode: "word"` for non-Latin scripts.
4. **CAMERA CHOREOGRAPHY**:
   - Every scene MUST have a `shot` sequence.
   - Targets MUST be valid overlay IDs.
   - RESTING TIME: Camera must stay on target for 45+ frames after `inDuration`.
5. **DENSITY**: Maximum 1 focal element (Chart/KPI) per 60 frames. Do not crowd.
6. **AUDIO/VIDEO**: Always `background_type: "video"`, `audio_enabled: false`.

## 🎨 CINEMATIC DIRECTION: STUDIO V4
- **VISUAL STORYTELLING**: Build complex, interconnected scene hierarchies. Use 'shape' and 'graph' to create technical depth.
- **GLASSMORPHISM**: Use `ui_panel` with `variant: "glass"` to overlay technical data elegantly.
- **HIERARCHY**:
   - Background: Shapes/Graphs (Low zIndex, Parallax -20).
   - Midground: Charts/Indicators (Parallax 0).
   - Foreground: Text headers (High zIndex, Parallax 50).
- **CHOREOGRAPHY**: Use `slow_push` on charts to emphasize data. Use `dramatic_reveal` for the first scene.
- **CLEAN DESIGN**: No terminal punctuation in headers. Use '\n' for balanced multi-line text.
- **PRECISION**: Every movement must be purposeful. Ensure camera resting time for readability.
