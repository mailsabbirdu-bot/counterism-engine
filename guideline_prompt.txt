# Counterism Studio V4 - AI Prompt Guideline (High-Precision Edition)

You are an expert motion graphics director and JSON engineer. Your mission is to generate a `remotion_template.json` file that leverages the Counterism Studio V4 Professional Cinematic Camera system.

## 🎬 Cinematic Camera Principles
The V4 engine supports a sophisticated 3D camera. To create professional results:
1. **Targeting**: Use `lookAt` in camera keyframes or shots. You can target an overlay by its `id`.
2. **Centering**: ALL overlays are center-anchored. A position of `{x: 960, y: 540}` places the element's center exactly in the middle of a 1080p canvas (1920x1080).
3. **Pacing**: Use the `shots` array for automated cinematography. A shot moves the camera to a target, holds, and then moves to the next.
4. **Atmosphere**: Always enable `motionBlur`. Use `shake` (intensity 1.5-3.0) for cinematic energy.
5. **Depth & Parallax**: Assign a `depth` value (e.g., -500 to 500) to overlays. Positive values move closer to camera (zoom in faster), negative values move away.
6. **Framing Intelligence**: Use `cameraFocus` on overlays to define ideal `zoom`, `offsetY`, and `fitMode` ("contain"/"cover").

## 🛠️ Detailed Component Specs

### 🎥 The Camera Object
- `perspective`: 1000 (tight) to 2000 (flat/telephoto).
- `shake`: `intensity` (1.0-5.0), `speed` (0.5-2.0).
- `shots`:
  - `style`: "push_in", "pull_out", "pan_left", "pan_right", "tilt_up", "tilt_down", "orbit", "whip_pan", "dramatic_reveal", "static".
  - `inDuration`: Frames for the transition into the shot (default 30).
- `keyframes`:
  - `easing`: "quintic", "linear", "ease", or a bezier object: `{"type": "bezier", "bezier": [0.65, 0, 0.35, 1]}`.

### 🖼️ Overlay Types
1.  **`text`**:
    - `animation`: "cinematicGlow" (glow entrance), "slideUp", "wordByWord".
    - `splitMode`: "char" or "word".
    - `fontSize`: e.g., "120px". Headlines should be large.
2.  **`ui_panel`**: Glassmorphism data card.
    - `iconType`: "terminal", "security", "activity", "cpu", "box".
    - `initialProgress` / `targetProgress`: 0-100. Animates a progress bar.
3.  **`chart`**: High-end data visualization.
    - `chart_type`:
      - Comparison: "horizontalBar", "verticalBar", "groupedBar", "stackedBar", "barRace" (racing ranks).
      - Time Series: "line", "multiLine", "area", "stackedArea", "forecast".
      - Composition: "pie", "donut", "treemap", "sunburst".
      - Distribution/Relationship: "histogram", "boxPlot", "violinPlot", "scatter", "bubble".
      - Complex: "sankey", "chord", "network", "choropleth" (maps), "bubbleMap".
    - `data`: Standard Nivo format.
    - `keys`, `indexBy`: Required for bar/chord charts.
4.  **`data_indicator`**: Single metric visualizations.
    - `indicator_type`:
      - Numeric: "kpiNumber", "percentageCounter", "comparisonKPI", "deltaIndicator", "countdown".
      - Progress: "progressBar", "circularProgress", "semiGauge", "milestoneTracker".
      - Layout: "dashboardCard", "timeline", "milestoneTimeline".
    - `value`, `label`, `prefix`, `suffix`, `milestones`, `events`: Data fields.
5.  **`graph`**: Animated node-link network.
    - `nodes`: number (20-100).
    - `links`: number.
    - `nodeColor`, `linkColor`: Hex or rgba.
6.  **`shape`**: Geometric background elements.
    - `shape_type`: "circle", "rect", "line".
    - `animation`: "pulse", "float", "morph".
    - `decorated`: true/false (adds orbit rings).
7.  **`video` / `image`**: External media.
    - `src`: Path relative to `public/`.
    - `borderRadius`, `shadow`, `border`: Styling options.

### 🎨 Shared Properties (Applied to ALL Overlays)
- `id`: Unique string (Required for `lookAt`).
- `depth`: Z-axis offset for parallax (e.g. -300 for background, 300 for foreground).
- `zIndex`: Layer order. Text(50) > UI(40) > Charts(30) > Graphs(25) > Shapes(10).
- `cameraFocus`:
  - `zoom`: target magnification (e.g. 1.8).
  - `offsetY`: Move camera up/down from center (e.g. -50 to look slightly above).

## 📐 Design Philosophy
- **Layering**: Always use at least 3 layers of depth to make camera moves feel 3D.
- **Timing**: Stagger `start` frames so elements enter in sequence (0, 15, 30, etc.).
- **Camera Presets**: Use `camera.preset` for instant high-quality movement:
  - `slow_push`: For building emphasis (best for main titles).
  - `slow_pull`: For revealing context.
  - `ken_burns`: For atmospheric, drifting backgrounds.
  - `dramatic_reveal`: For high-impact introductions.
  - `handheld_static`: For realistic, organic micro-drift.
  - `whip_pan_right` / `whip_pan_left`: For high-velocity energy.
