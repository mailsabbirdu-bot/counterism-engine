# GEMINI INPUT INJECTION DISCLOSURE - COUNTERISM STUDIO V4

## 1. PHASING
The interaction with Gemini is **SINGLE-PHASE**. The entire context, guidelines, durations, and story are injected in one massive "Master Prompt" to ensure the AI has global context of the project before generating the JSON. This minimizes hallucinations and avoids context fragmentation.

## 2. INJECTED DATA COMPONENTS
The prompt is dynamically constructed using the following parts:

### A. System Directives & Schema Rules
Strict instructions forcing Gemini to act as a "Remotion Master Engine". It includes:
- **Mandatory JSON formatting**: Start '{' End '}'.
- **Key Remapping Rules**: Forcing `overlays` (instead of elements), `content` (instead of text), `start/duration` (instead of frame indices).
- **Design Constraints**: Minimalist budget (Max 1 text, 1 focal per scene), cinematic pacing (15f intro/outro), and balanced quadrant placement.

### B. Reference Schema
A minified, 100% valid 1-scene JSON example is injected to "ground" the AI's structural output.

### C. Local Font Context
A recursive scan of `public/fonts/` is performed. The detected fonts are categorized into `BANGLA_FONTS` and `ENGLISH_FONTS` using keyword heuristics. This list is injected so Gemini only selects fonts that exist on the local machine.

### D. Authoritative Durations (`fps_update.txt`)
Scene durations are parsed from the external `fps_update.txt`. They are injected as `DURATIONS (30fps): SCENE_01:XXf, SCENE_02:YYf...`. Gemini is told to strictly respect these frame counts.

### E. Word-Level Timestamps (`timestamp.txt`)
The verbose `timestamp.txt` is compacted into a space-efficient format: `SCENE_XX:StartFrame "Word"`. This tells Gemini exactly when the voiceover starts each word, allowing it to sync the `start` frame of text overlays to specific audio cues.

### F. Story Script (`story.txt`)
The raw narrative script, segmented into scenes.

### G. Visual Guidelines (`guideline.md` & `guideline_prompt.txt`)
Cinematic design principles and engine-specific technical constraints.

## 3. POST-PROCESS REPAIR (EXTREME RESILIENCE)
After Gemini provides the raw string, the engine performs a non-AI multi-stage repair:
1. **Regex Pre-Pass**: Fixes "swallowed quotes" (e.g., `"id":"val,"next"`) and numeric artifacts (e.g., `30f`).
2. **Structural Backtracking**: If the JSON is truncated, the engine iteratively trims the string and re-calculates the brace/bracket stack until it finds the last valid JSON structure.
3. **Schema Finalization**: A programmatic pass that enforces quadrants (Charts RIGHT, Text LEFT), adds missing camera shots, and guarantees cinematic resting time.
