# PRODUCTION DESIGN PROTOCOL: SVG ENGINE

## 🎯 DESIGN INTENT
Produce high-fidelity procedural infographics (Vox/Polymatter style).

## 🛠️ COMPONENT ARCHITECTURE
- **HubNetwork**: For global systems. Center SVG must be from 'simple-icons' (e.g., 'amazon', 'apple').
- **KpiCard**: High-impact metrics. Use numeric 'value' for counters.
- **FlowDiagram**: For sequential logic.
- **Groups**: Wrap multiple overlays to move them as one.

## 🎨 BROADCAST AESTHETICS
1. **TYPOGRAPHY**: Massive scale. Labels 72px+, KPIs 96px+.
2. **CONNECTIONS**: Use 'infographic_lines' with `from_id` and `to_id`.
3. **SPACING**: Min 300px between centers. No overlaps.
4. **PACE**: Stagger entries by 15 frames.
5. **THEME**: Always use `style: "tech"`.

## 📦 JSON CONTRACT
- Use `overlays` array for all components.
- Use `camera.shots` to target specific component IDs.
